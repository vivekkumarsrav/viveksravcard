# Vivek K. SRAV — Profile Card

A responsive personal profile card for Vivek K. SRAV.

## Features
- Responsive desktop and mobile layout
- Personal portrait and introduction
- Social profile links
- Dark/light theme toggle
- Copy current page URL button

## Files
- `index.html` — page structure
- `style.css` — layout, colors, responsive styles
- `script.js` — theme and copy-link interactions
- `vivekkumarsrav.png` — profile portrait
- `googledecd292028cdf120.html` — Google site-verification file
- `sitemap.xml` — sitemap

## Preview locally
Keep all files in this folder. Open `index.html` in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.

## Deployment note
The current canonical and sitemap URLs point to `https://vivekkumarsrav.github.io/`. If you publish this folder as a subfolder inside another GitHub Pages repository, update the canonical URL and sitemap URL to the actual published subfolder URL. For Google Search Console verification of the site root, keep the verification HTML file at the published site root as well.
